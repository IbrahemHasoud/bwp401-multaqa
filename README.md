# ملتقى — مشروع BWP401

موقع ثابت من خمس صفحات، بنسختين عربية وإنجليزية. ملفات الموقع الجاهزة للاستضافة موجودة في جذر المستودع. ملف التسليم ZIP يحتوي هذه الملفات مباشرة، بحيث يكون `index.html` في جذره.

## التشغيل

افتح `index.html`، أو ارفع ملفات الموقع إلى استضافة مواقع ثابتة مثل GitHub Pages. لا توجد حزم تحتاج إلى تثبيت أو قاعدة بيانات أو خطوة بناء.

تُحمّل Bootstrap 5.3.3 عبر CDN كما تطلب ورقة الوظيفة، مع نسخ محلية احتياطية عند تعذر الاتصال. الصور والخطوط محفوظة محليًا. تُحفظ تفضيلات اللغة والمظهر في localStorage عند سماح المتصفح بذلك. يعمل الحفظ والتنقل بصورة موثوقة عند التشغيل من استضافة HTTP/HTTPS.

## الصفحات

- `index.html`: السلايدر والتصنيفات وأحدث الفعاليات وأسماء الفريق ومعرّفاتهم وصفوفهم.
- `events.html`: البحث والفلترة المتزامنة حسب التصنيف والتاريخ والمكان، وحالة عدم وجود نتائج.
- `event.html?id=web-lab`: تفاصيل الفعالية، معرض، مخطط موقع توضيحي، تنزيل التقويم والمشاركة والفعاليات المرتبطة. تعرض الصفحة تفاصيل مختلفة لتسع فعاليات باستخدام المعرّف في الرابط.
- `about.html`: الهدف والرؤية والرسالة والفريق وسياسات النشر ومصادر الصور.
- `contact.html`: نموذج تواصل يتحقق من الحقول ويعرض رسائل نجاح وخطأ.
- `en/`: ترجمة الصفحات الخمس إلى الإنجليزية، باتجاه LTR.

## التقنيات ومراجع المقرر

- HTML والروابط والصور: CH1؛ النماذج وHTML5 وSVG: CH2.
- CSS والألوان والخطوط ونموذج الصندوق: CH3.
- متغيرات ووظائف ومصفوفات وشروط وتعابير نمطية: CH4.
- DOM والأحداث والتحقق من الإدخال: CH5.
- تغيير التنسيق وإظهار العناصر وإخفاؤها: CH6.
- Bootstrap وGrid وFlexbox والتجاوب وCDN وإضافة التقويم والمشاركة مطلوبة في ورقة المشروع.
- الوضع الداكن وحفظ التفضيلات إضافتان مذكورتان في ورقة المشروع. الترجمة إضافة طلبها المستخدم.

لم يُستخدم إطار تطبيقات أو مخدم أو تقنيات قواعد بيانات؛ التنفيذ الذي يدرسه الطلاب هو HTML وCSS وJavaScript مع Bootstrap المطلوب. ملفات HTML الإنجليزية ثابتة، ولا تعتمد على خدمة ترجمة.

## حدود النسخة

الفعاليات والمواعيد والأماكن أمثلة تجريبية وليست إعلانات رسمية. رموز الفريق أحرف أسمائهم وليست صور أشخاص. النموذج يتحقق محليًا دون إرسال أو تخزين الرسائل؛ عنوان البريد المعروض توضيحي. لا توجد حسابات تواصل اجتماعي رسمية لهذا المشروع؛ روابط المنصات في التذييل تشير إلى المنصات نفسها.

## الصور والتراخيص

مصادر الصور في `IMAGE-SOURCES.md` وصفحة عن الدليل. خط Cairo من Google Fonts بترخيص OFL المرفق. Bootstrap بترخيص MIT. صور Pexels توضيحية ولا توثّق الجامعة أو فعالياتها.
